Interface geometry and volume-of-fluid kernels

Tesserae.PLIC and Tesserae.VOF provide local calculations for two- and three-dimensional Cartesian cells. The free-surface tutorial uses them to transport water on a MAC grid. The modules allocate no field arrays and prescribe no boundary conditions, time step, material data or pressure solver.

Plane and box geometry

A plane with normal $\boldsymbol{n}$ and offset $a$ defines the filled side $\boldsymbol{n}\cdot\boldsymbol{x}\leq a$. The reference cell is $[-1/2,1/2]^N$. Normals and box corners are Vec values. Normals must be finite and nonzero but need not be normalized. Use the same floating-point type for the normal, offset or fraction, and box corners. Float32 and Float64 inputs retain their precision.

julia> using Tesserae: PLIC, Vec

julia> n = Vec(1.0, 0.0);

julia> PLIC.plane_fraction(n, 0.0)
0.5

julia> PLIC.plane_offset(n, 0.25)
-0.25

julia> PLIC.box_volume(n, 0.0, Vec(-0.5, -0.5), Vec(0.0, 0.5))
0.5

plane_fraction returns a fraction of the reference cell; box_volume returns the absolute area or volume inside the supplied sub-box. The geometric inverse PLIC.plane_offset requires a fraction in $[0,1]$.

Tesserae.PLIC.plane_fraction — Function
plane_fraction(n, α)

Fraction of the centered unit square or cube [-1/2,1/2]^N satisfying n⋅x ≤ α. In 2D the boundary is a line and the fraction is an area fraction; in 3D it is a plane and a volume fraction. n is a nonzero, finite two- or three-dimensional Vec; its length need not be normalized. The cut is computed analytically in the input precision.

source
Tesserae.PLIC.plane_offset — Function
plane_offset(n, fraction)

Find α such that plane_fraction(n, α) == fraction, up to roundoff. fraction must lie in [0,1]. Empty and full cells return the supporting lines or planes of the square or cube; a half-full cell returns zero. All branches are analytic.

source
Tesserae.PLIC.box_volume — Function
box_volume(n, α, lower, upper)

Measure of the region n⋅x ≤ α inside an axis-aligned rectangle or box: area in 2D, volume in 3D. Coordinates use the same frame as plane_fraction. This returns an absolute area or volume, not a fraction of the rectangle or box. The calculation maps to a centered unit square or cube. Zero widths return zero.

Interface reconstruction

myc_normal(fraction, I) estimates the MYC normal at an ordinary CartesianIndex. It reads one surrounding layer for mixed cells; a pure center uses the positive-x convention because there is no local interface to reconstruct. Both estimators return Vec normals. myc_direction also reads the neighbors at pure centers, as needed by some free-surface pressure discretizations. The caller fills any required halo.

The normal uses reference-cell coordinates. On a rectangular grid, normal ./ spacing gives its physical direction. A normal estimator can be replaced independently of the PLIC geometry and donor flux.

Tesserae.VOF.myc_normal — Function
myc_normal(fraction, I)

VOF interface normal at the Cartesian index I in a two- or three-dimensional fraction array. Mixed cells read the surrounding 3×3 or 3×3×3 neighborhood and return an outward Vec normal with unit L1 norm in reference coordinates. On rectangular grids, normal ./ spacing gives its physical direction. Arbitrary planar interfaces are not guaranteed to be exact.

The center must be finite. Empty/full cells (center ≤ 0 or ≥ 1) have no interface in the cell and return the positive x convention without estimating a normal from neighbors. Mixed cells require finite neighboring fractions. Fractions are never changed or clipped; the transport scheme owns their bounds, including roundoff. The caller supplies any required boundary values. Missing neighbors raise BoundsError unless bounds checks are explicitly disabled. The MYC zero-gradient guards use a 1e-30 component bias in 2D and a 1e-30 magnitude cutoff in 3D.

source
Tesserae.VOF.myc_direction — Function
myc_direction(fraction, I)

MYC direction from the full 3×3 or 3×3×3 neighborhood of I, including when the center is empty or full. Unlike myc_normal, this always estimates the direction from neighboring fractions. For example, a free-surface pressure stencil can need that direction at a pure pressure cell adjacent to the interface.

The array must be two- or three-dimensional and the required neighbors must be finite. The result has unit L1 norm in reference coordinates. The caller supplies boundary values; missing neighbors raise BoundsError unless bounds checks are explicitly disabled. Fractions are read without being changed or clipped.

source

Use PLIC.plane_offset(n, c) to locate the plane for a fraction in [0, 1]. If the transport calculation can leave small finite excursions outside this interval, the caller can pass clamp(c, zero(c), one(c)) to the geometric inverse. The stored fraction still enters the transport balance directly.

Geometric donor flux

The signed displacement is $\lambda=u\Delta t/h$. VOF.flux computes the filled volume swept from one selected donor cell, divided by that whole cell's volume. Its sign chooses the donor's positive or negative face. The caller selects the donor and writes the face-flux difference in the conservation law. Pass the donor fraction, normal and offset for a precomputed plane, or pass the fraction field and donor index to reconstruct that cell with MYC. The geometric kernel supports $|\lambda|\leq1$; a complete transport scheme can impose a stricter CFL bound. The dam-break tutorial uses 0.25.

Tesserae.VOF.flux — Function
flux(displacement, fraction, normal, offset, axis)
flux(displacement, fraction_field, donor::CartesianIndex, axis)

Signed filled volume swept out of one donor cell, divided by its whole volume. The caller selects the donor cell. displacement = velocity*dt/spacing chooses its positive or negative face and must be finite with magnitude at most one. The complete advection scheme can impose a stricter CFL bound (WY uses 1/2).

normal and offset describe the filled region in the centered unit cell. The normal is a two- or three-dimensional Vec. Empty/full fractions use displacement*fraction, retaining transport roundoff without clipping. The caller monitors field bounds. Mixed cells use analytic plane/box geometry. With a fraction field and donor index, use the same floating-point type for displacement and the field elements. Mixed donors use MYC reconstruction from one surrounding layer, including diagonals. The caller supplies the halo when that neighborhood crosses a physical boundary. Pure donors need only the center value.

source

The scalar kernels can be used in native broadcast and @stencil expressions on CPU and GPU arrays. This does not select a GPU pressure solver for the complete tutorial.
