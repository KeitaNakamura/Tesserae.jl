Finite-volume heat diffusion

Temperature is stored at cell centers and heat flux at face centers. We solve ∂T/∂t = -∇⋅q with q = -α∇T on the unit box, using zero boundary temperature and forward Euler time integration. The same code works in two or three dimensions.

using Tesserae.Stencil

function main(n=(32, 24); α=0.1, t_end=0.1)
    N = length(n)
    h = 1 ./ n
    x = ntuple(d -> ((1:n[d]) .- 0.5) .* h[d], N)
    T = [prod(sinpi(x[d][J[d]]) for d in 1:N) for J in CartesianIndices(n)]

    # Face dimensions and array backend follow from the source and target placements.
    q = ntuple(d -> similar(T, Cell(), Face(d)), N)
    rate = similar(T)
    C = Region(Cell(), Val(N))
    offsets = unitoffsets(Val(N))

    dtmax = 0.2 / (α*sum(hd -> hd^(-2), h))
    nsteps = ceil(Int, t_end/dtmax)
    dt = t_end/nsteps

    for _ in 1:nsteps
        fill!(rate, 0)
        for d in 1:N
            F = Region(Face(d), Val(N))
            I = interior(F)
            L, R = boundaries(F, d)
            f, e, hd = q[d], offsets[d], h[d]

            # Internal fluxes use the two cells half a cell away from each face.
            @views @. f[I] = -α*(T[I+e/2] - T[I-e/2])/hd

            # Each boundary face is half a cell away from its adjacent cell center.
            @views @. f[L] = -α*T[L+e/2]/(hd/2)
            @views @. f[R] =  α*T[R-e/2]/(hd/2)

            # Update every cell, including the cells touching the boundary.
            @views @. rate[C] -= (f[C+e/2] - f[C-e/2])/hd
        end
        @. T += dt*rate
    end

    T
end

Region represents a placement and a selection, not an array. Concrete ranges are resolved when indexing an array; @views produces ordinary views, and @. uses Julia's standard broadcast. There is no separate execution API.

interior preserves placement and excludes sampling points on the boundary. Thus interior(C) contains all cell centers, whereas interior(F) excludes the two boundary faces normal to d. Arrays have no halo in this example.

The flux formula can also be written with its index anchored at the lower cell. With J = I-e/2, the exact same operation is @views @. f[J+e/2] = -α*(T[J+e]-T[J])/hd. Both forms use the same region and displacement arithmetic.

T2D = main()
T3D = main((12, 10, 8))
